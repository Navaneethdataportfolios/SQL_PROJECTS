# SQL_PROJECTS
# Top Company Layoffs Analysis Using MySQL

## Project Overview
This project analyzes company layoffs using SQL to identify the companies with the highest number of layoffs and explore trends in layoffs over time.

## Tools Used
- MySQL
- MySQL Workbench

## Key Analysis
- Identified companies with the highest layoffs.
- Analyzed layoffs by year and month.
- Calculated rolling totals.
- Ranked companies based on total layoffs.

## Skills Demonstrated
SQL Data Cleaning, Aggregate Functions, CTEs, Window Functions, and Exploratory Data Analysis.
